   feature branch; no production state or migration exists.
2. After a separately authorized merge, revert the v0.4.22 merge commit. Image
   and Animation export code, dynamic dependency, UI, messages, and speed field
   are additive and can be reverted together.
3. Existing documents remain readable because `animation.speed` is optional
   and defaults to 1×. No database rollback is required.
4. If only video delivery is unsafe, disable the Animation export entry in a
   reviewed follow-up while retaining Project download/import and image export;
   do not silently substitute a lower profile.
