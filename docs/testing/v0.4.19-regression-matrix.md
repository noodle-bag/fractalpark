## Release interpretation

- A green prototype row is not production activation.
- A private legacy projection or synthetic contract does not create a publication
  decision or runnable implementation.
- Public activation requires exactly 677 catalog identities and exactly 677
  `publish | hold | exclude` decisions. Runtime, canonical source, default Profile,
  preview, and Remix exist only for the published-N subset.
- All 73 GPL identities remain held outside the current MIT implementation bundle.
- Unclosed work holds the affected row; it does not block unrelated published rows.
- Merge, Production migration, writer enablement, deployment, tag, release, and
  IndexNow remain separate authorization gates.
