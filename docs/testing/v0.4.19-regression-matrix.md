## Release interpretation

- A green prototype row is not production activation.
- A partial 677 candidate may run only behind test/Preview gates.
- Public Standard activation is all-or-nothing: 677 identities, Definitions,
  Profiles, resolver, rights, conformance, and rollback evidence must close.
- Merge, Production migration, writer enablement, deployment, tag, release, and
  IndexNow remain separate authorization gates.
