# v0.4.22 Static Export and Preview Prototype

- Status: Slice 0a implementation evidence
- Scope: format probing, representative composition/quality samples, and a browser-engine matrix
- Product activation: none

## Boundary

This prototype validates the static-image and composition assumptions required
before the production Export Job or workspace is implemented. The code under
`src/prototypes/` is test-only and has no production importer. It does not
replace `src/lib/export-fractal.ts`, change a Document, add UI, or enable a new
format.

Approved product inputs represented here are PNG and JPEG, exact returned Blob
MIME validation, the `8192 px` single-side and `16,777,216 px` total-pixel hard
limits, JPEG quality hints `0.82 / 0.92 / 1.00`, and normalized Fit / Fill /
Custom composition shared by low-resolution preview and final output.

## Representative samples

The isolated Playwright probe synthesizes one deterministic field containing:

- dark gradients and bands;
- fine lines and sharp edges;
- high-frequency detail;
- alpha that must remain meaningful for PNG and be composited onto an explicit
  background before JPEG encoding.

Each browser project attaches decoded PNG/JPEG samples and a capability JSON to
its Playwright test result. Attachments are transient evidence outputs, not
checked-in product assets. Preview and final samples derive the same camera from
normalized composition parameters instead of scaling a preview bitmap.

An AVIF request is recorded only to prove that requested MIME cannot be trusted:
the probe accepts either native AVIF or the browser's PNG fallback as observed
capability data. AVIF remains outside v0.4.22 regardless of that observation.

## Interpretation and remaining gates

A passing prototype freezes the static composition and capability evidence for
Slice 0a only. It does not activate product behavior or satisfy later UI,
WebGL-output, real-device, accessibility, animation, Production, or release
gates. Playwright WebKit is browser-engine evidence and must not be reported as
real Safari evidence.
